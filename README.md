# lookmv — سایت واقعی فیلم

نسخهٔ کامل سایت (غیر preview) با ورود/ثبت نام، پروفایل، کاتالوگ یکپارچه از دو دیتابیس، فیلم ویژهٔ روزانه و تریلر خودکار.

## اجرا

```bash
cd ~/lookmv
chmod +x start.sh
./start.sh
```

سایت: <http://localhost:3000> — در مرورگر باز کنید، ثبت نام کنید و وارد شوید.

پورت دیگر: `PORT=8080 ./start.sh`

## آنچه تغییر کرد

- **صفحهٔ ورود**: قبل از ورود به سایت، ورود / ثبت نام (ایمیل + رمز عبور). رمزها با `scrypt` و salt ذخیره میشوند، نه متن ساده.
- **پروفایل**: سه گزینهٔ قدیمی حذف شدند. اکنون: تغییر ایمیل، تغییر رمز، خروج از حساب، حذف حساب (همه با تأیید رمز).
- **کاربران**: در `data/users.json` ذخیره میشوند (و نشستها در `data/sessions.json`).
- **لیست من**: فقط در `localStorage` مرورگر ذخیره میشود، روی سرور چیزی ذخیره نمیشود.
- **کاتالوگ**: از `atlasmind_all.json` و `animex_database.json` ساخته شد؛ ۱۲٬۴۸۳ عنوان بعد از حذف ۳۰۹ مورد تکراری (اگر فیلمی در هر دو دیتابیس بود، فقط یکی نگه داشته شد).
- **فیلم ویژه**: هر ۲۴ ساعت (نیمه شب به وقت تهران) یک فیلم تصادفی به صورت قطعی انتخاب میشود.
- **تریلر و اطلاعات**: نمرهٔ IMDb، سال ساخت، خلاصه و تریلر به صورت خودکار از API گرفته میشود و کش میشود (`data/enrich-cache.json`).
- **دانلود و پخش**: لینکهای واقعی همان دیتابیسها در باکس دانلود و پلیر استفاده میشوند.

## API های رایگان اطلاعات فیلم

فایل `config.json` دو کلید اختیاری دارد:

```json
{ "omdbKey": "", "tmdbKey": "" }
```

- **OMDb** (رایگان): نمرهٔ IMDb، سال، خلاصه، پوستر — <https://www.omdbapi.com/apikey.aspx>
- **TMDb** (رایگان): تریلر یوتیوب، پوستر و توضیحات — <https://www.themoviedb.org/settings/api>

اگر کلیدها خالی بمانند، سرور از منابع بدون کلید (Jikan، TVmaze، IMDb غیررسمی و جستجوی یوتیوب) استفاده میکند. نتیجهٔ هر جستجو ۷ روز کش میشود تا از محدودیتAPIها جلوگیری شود.
اگر اینترنت در دسترس نباشد، سایت بدون تریلر و با اطلاعات موجود در دیتابیس کار میکند.

## ساخت مجدد کاتالوگ

پس از بروزرسانی فایلهای JSON منبع:

```bash
node scripts/build-movies.js
```

## ساختار فایلها

```
lookmv/
├── server.js              # سرور و تمام endpoint ها
├── config.json            # کلیدهای API (اختیاری)
├── public/index.html      # رابط کاربری
├── data/
│   ├── movies.json        # کاتالوگ یکپارچه (ساخته شده)
│   ├── users.json         # حسابهای کاربران
│   ├── sessions.json      # نشستها
│   └── enrich-cache.json  # کش اطلاعات فیلمها
└── scripts/build-movies.js
```

## تغییرات نسخهٔ ۲

- **قسمت و فصل**: در دیتابیس فیلد `ep` همیشه خالی بود، برای همین هر سریال «تک‌قسمتی» حساب می‌شد. حالا سرور موقع بالا آمدن، فصل و قسمت را از نام فایل لینک‌ها (`S01E05`، `E012`، `- 05` ...) می‌خواند. لینک‌هایی که فقط پوشهٔ فصل هستند جدا و با برچسب «پوشه» نشان داده می‌شوند.
- **تماشا**: سریال → اول لیست قسمت‌ها (قابل انتخاب)؛ فیلم → مستقیم پخش.
- **باکس دانلود**: سریال = لیست قسمت‌ها (و انتخاب فصل)، با زدن هر قسمت کیفیت‌ها باز می‌شود. هر بار ۸۰ قسمت نمایش داده می‌شود و دکمهٔ «نمایش بیشتر» بقیه را می‌آورد.
- **کاور، سال، نمره**: `GET /api/covers?ids=...` برای کارت‌ها یک‌جا پوستر، سال و نمره می‌گیرد (کش ۷ روزه). کلید TMDb یا OMDb در `config.json` دقت و سرعت را بالا می‌برد.
- **دکمهٔ دانلود روی کاور**: فیلم مستقیم (بهترین کیفیت) دانلود می‌شود؛ سریال باکس دانلود را باز می‌کند.
- **دکمهٔ ذخیره (لیست من)**: دیگر فیلم را باز نمی‌کند؛ در «لیست من» کارت بلافاصله حذف می‌شود.
- **تریلر**: با انتخاب کاور، اگر «پخش خودکار تریلر» روشن باشد خودکار (بی‌صدا) پخش می‌شود و با خروج از صفحه متوقف می‌شود.
- **فیلم ویژه**: کاور پس‌زمینه + سال و نمره؛ «تماشا» مستقیم لیست تماشا، «دانلود» ورود به صفحهٔ فیلم.

## استقرار با Docker روی Railway

پروژه مستقیماً با Dockerfile ساخته می‌شود و به نصب هیچ پکیج npm نیاز ندارد.

1. محتوای این پوشه را در یک GitHub repository قرار دهید و در Railway از گزینهٔ **Deploy from GitHub Repo** همان مخزن را انتخاب کنید.
2. در بخش **Volumes** یک Volume بسازید و مسیر Mount آن را دقیقاً `/app/storage` قرار دهید. این مسیر اطلاعات کاربران، نشست‌ها و کش را نگه می‌دارد؛ فایل کاتالوگ فیلم‌ها جداگانه در `/app/data` باقی می‌ماند.
3. متغیرهای زیر را در بخش Variables قرار دهید:

```env
STORAGE_DIR=/app/storage
HOST=0.0.0.0
TMDB_API_KEY=YOUR_TMDB_V3_API_KEY
OMDB_API_KEY=YOUR_OMDB_API_KEY
```

`PORT` را دستی ثابت نکنید؛ Railway مقدار آن را هنگام اجرا تنظیم می‌کند. کلیدهای TMDb و OMDb اختیاری‌اند، اما برای دریافت فهرست روزانهٔ واقعی Top 10 و Latest از TMDb، مقدار `TMDB_API_KEY` را تنظیم کنید.

### رفتار صفحهٔ خانه

- فهرست‌های Top 10 و Latest روزی یک‌بار (بر اساس روز تهران) تازه‌سازی می‌شوند. از داده‌های روزانه، هر بار ورود به صفحهٔ خانه ۱۰ عنوان به‌شکل تصادفی انتخاب و مرتب می‌شود.
- برای حفظ امکان تماشا و دانلود، عنوان‌های TMDb فقط وقتی نمایش داده می‌شوند که در کاتالوگ محلی سایت و دارای لینک باشند؛ در صورت کم بودن تطبیق‌ها، فهرست با داده‌های کاتالوگ تکمیل می‌شود.
- بدون کلید TMDb هم برنامه اجرا می‌شود و فهرست‌های روزانه را از کاتالوگ محلی می‌سازد؛ در این حالت دریافت تازهٔ داده از TMDb انجام نمی‌شود.
- بخش «پیشنهاد برای شما» ژانرهای عنوان‌های My List مرورگر را می‌خواند و آثار هم‌ژانرِ ذخیره‌نشده را تصادفی پیشنهاد می‌کند.
- نوشتهٔ عنوان و حروف اختصاری از روی تصویر پوستر حذف شده‌اند؛ عنوان فیلم فقط در بخش متن کارت دیده می‌شود.

### اجرای محلی با Docker

```bash
docker build -t lookmv .
docker run --rm -p 3000:3000 \
  -e STORAGE_DIR=/app/storage \
  -v lookmv-data:/app/storage \
  -e TMDB_API_KEY=YOUR_TMDB_V3_API_KEY \
  lookmv
```

سپس `http://localhost:3000` را باز کنید. برای بررسی سلامت سرویس نیز مسیر `/health` در دسترس است.

## تغییرات نسخهٔ ۵ — کاتالوگ زنده، بدون دیتابیس جداگانه

- **دیگر از `data/movies.json` بهعنوان دیتابیس اصلی استفاده نمیشود.** لیست فیلمها، سرچ، دستهبندیها، جدیدترینها و برترینها مستقیم از API دو سایت خوانده میشوند (`public/source-catalog.js`).
- **animex.pro**: `/wp-json/app/v1/items` (لیست، sort=latest|rating|year، فیلتر genre/year/type/page)، `/search?q=...`، `/genres` و `/items/<id>` (همه کیفیتها، فصل و قسمتها از `download_groups`).
- **atlasmind.top**: `/wp-json/wp/v2/posts` و `/series` همراه `_embed=1` (عنوان، کاور، خلاصه، سال، دستهبندی)، `/categories` و `/search`.
- **نتایج سرچ هر دو سایت با هم نمایش داده میشوند** (بدون حذف تکراری) و منبع روی هر کارت مشخص است.
- **عنوانها کامل و تمیز میشوند**: عبارات «دانلود فیلم/سریال»، «بدون سانسور»، «زیرنویس فارسی چسبیده»، «با» و سال ساخت جدا میشوند؛ نام فارسی و نام اصلی (English) جداگانه استخراج میشوند و سال در فیلد مخصوص خود نشان داده میشود.
- **دستهبندیها** از اتحاد ژانرهای animex و دستهبندیهای atlasmind ساخته میشوند (حدود ۱۳۵ مورد).
- **کیفیت/فصل/قسمت**: animex کاملاً زنده است. لینک دانلود atlasmind چون فقط در HTML صفحه است (و آن صفحه CORS ندارد) از **کش کوچک لینکها** در `movies.json` خوانده میشود؛ بقیهٔ اطلاعات همان فیلم زنده است.
- **fallback**: اگر API سایتی در دسترس نباشد، همان لیست از کاتالوگ محلی قدیمی سرو میشود؛ سرور در هنگام بالا آمدن هیچ درخواست خارجی نمیکند.
- شناسهها: `ax-<siteId>` برای animex و `am-<siteId>` برای atlasmind. لیست من و نظرات همانند قبل در `localStorage` هستند.

## تغییرات نسخهٔ ۴ — درخواست‌ها از مرورگر، نه سرور

- **کاور، خلاصه، نمره و سال** حالا کاملاً سمت مرورگر گرفته میشود (`public/source-meta.js`). سرور هیچ درخواستی به TMDb/OMDb/سایر API بیرونی نمیکند و نیازی به کلید API نیست.
- هر دو دیتابیس منبع وبسایت WordPress هستند و مسیر `wp-json` آنها هدر CORS را به Origin مرورگر برمیگرداند:
  - **atlasmind** (`.top` / `.net`): `GET /wp-json/wp/v2/posts/<id>?_embed=1` یا `.../series/<id>?_embed=1` (همچنین `?slug=...` و `/wp/v2/search?search=...`). از پاسخ، `excerpt.rendered` (خلاصه)، `_embedded['wp:featuredmedia'][0].source_url` (کاور) و تاریخ/عنوان (سال) خوانده میشود. نمرهٔ موجود در کاتالوگ محلی (`siteRating`) با برچسب «سایت» نمایش داده میشود.
  - **animex.pro**: `GET /wp-json/app/v1/search?q=...&per_page=8` سپس `GET /wp-json/app/v1/items/<id>` (و `/extras` برای تریلر). فیلدها: `poster`، `backdrop`، `year`، `synopsis`، `imdb_rate`، `mal_rate` (انیمه) و `mdl_rate` (سریال). بسته به نوع عنوان، نمرهٔ مناسب (IMDb / MAL / MDL) انتخاب و برچسب آن هم نمایش داده میشود.
- نتایج به مدت ۷ روز در `localStorage` کش میشوند (نتایج خالی ۳۰ دقیقه)، حداکثر ۲۵۰۰ رکورد. همزمانی درخواستها محدود (۵) و درخواستهای تکراری یکجا میشوند.
- انتخاب «فیلم ویژهٔ روز» و بارگذاری اطلاعات آن هم در مرورگر انجام میشود؛ `/api/featured` فقط عنوان کاتالوگ روز را برمیگرداند.
- در صورت عدم دسترس بودن سایت منبع، کارتهای کاتالوگ با گرادیانت و اطلاعات محلی همانطور که قبلاً کار میکردند نمایش داده میشوند.

## تغییرات نسخهٔ ۳ — درخواست‌ها از سرور، نه مرورگر

- **کاور، خلاصه، نمره و سال** فقط توسط سرور از TMDb / OMDb / Jikan / TVmaze / IMDb گرفته می‌شود. مرورگر مستقیماً به هیچ‌کدام از این سایت‌ها درخواست نمی‌زند.
- **پروکسی تصویر**: سرور هر پوستر/بک‌دراپ را یک بار دانلود می‌کند، در `STORAGE_DIR/img-cache` ذخیره می‌کند (۳۰ روز) و با مسیر `/img/<id>` به کاربر می‌دهد. فقط آدرس‌هایی که خود سرور ثبت کرده قابل دریافت‌اند (پروکسی باز نیست) و نیاز به ورود دارد. اگر منبع اصلی از دسترس خارج شود، نسخهٔ ذخیره‌شده سرو می‌شود.
- **فیلم ویژه**: `GET /api/featured` حالا خلاصه، نمره، سال و تصویر پس‌زمینه را یک‌جا (و آمادهٔ نمایش از روی دیسک سرور) برمی‌گرداند. تصویر همیشه پس‌زمینهٔ بخش ویژه است (بک‌دراپ TMDb با کیفیت ۱۲۸۰؛ در نبود آن پوستر؛ و اگر هیچ تصویری پیدا نشد، گرادیان اختصاصی همان فیلم). فیلم ویژه هنگام بالا آمدن سرور از قبل گرم می‌شود.
- تنها درخواست مستقیم مرورگر به بیرون: پخش تریلر (iframe یوتیوب) و فونت‌های Google Fonts.

## تغییرات نسخهٔ ۹

- نشان «★ فیلم ویژه امروز» از بالای صفحهٔ خانه حذف شد.
- متن «اطلاعات از: …» / «اطلاعات تکمیلی در دسترس نیست» در صفحهٔ فیلم حذف شد.
- سرعت انیمیشنها تقریباً نصف شد: باز شدن کیفیتها و قسمتها (~۰٫۴۵s)، ورود کارتها، انتقال بین صفحات و جابهجایی تم (~۱٫۳s) همه سریعترند.

## تغییرات نسخهٔ ۸

- کلمهٔ «FILM2MEDIA» از برچسبهای دانلود فیلتر میشود (هم بهعنوان tok و هم در متن جایگزین نام فایل).
- ردیف «جدیدترینها» از کش محلی (`lm_home_v1`) فوراً نمایش داده میشود و تازهسازی در پسزمینه انجام میشود؛ با رفتن به تب خانه لیست پاک و دوباره رندر نمیشود و همان المانها باقی میمانند.
- عنوان ردیف دوم به «برتر امروز» (En: «Top today») تغییر کرد و عدد «۱۰» از کنار آن حذف شد.

## تغییرات نسخهٔ ۷ — رفع مشکلات باکس دانلود و پخش

- **برچسبها از روی نام فایلها ساخته میشوند** (`niceLabel`): ورژن (دوبله/زیرنویس فارسی چسبیده/نسخه اصلی)، انکودر و امکانات فایل (x265، 10bit، WEB-DL، 6CH، Film2Media، MixFlixTop…) استخراج میشود؛ کیفیت تکراری و اطلاعات مخلوط حذف میشوند. پنج فایلی که قبلاً همگی «Persian dub» بودند اکنون هرکدام نام متمایزی دارند.
- **خلاصهها پاکسازی میشوند**: علامت `...` / `&hellip;` / `[…]` انتهای متن حذف میشود.
- **فصلبندی درست**: عناوین گروهی animex مانند «دانلود فصل اول/دوم» و نشان `S2` در نام فایل تشخیص داده میشوند؛ قسمتها در فصل مربوطه قرار میگیرند و برچسب «فصل» بهجای شمارهٔ اشتباه نمایش داده میشود.
- **فیلتر نام فایل**: شمارهٔ فصل و قسمت و جزئیات کیفیت از نام فایل خوانده میشود، نه از فیلدهای تکراری سایت.
- **منوی پخش**: هنگام تماشای سریالهای چندفصله، دکمههای «فصل ۱ / فصل ۲…» بالای لیست قسمتها قرار دارد و با زدن هرکدام فقط قسمتهای همان فصل نمایش داده میشوند.
- **دکمهٔ تماشا کنار هر دانلود**: در باکس دانلود (هم کیفیتها و هم قسمتها) هر فایل یک دکمهٔ SVG پخش دارد که همان لینک را مستقیم در پلیر باز میکند.

## تغییرات نسخهٔ ۶

- **اکاردیون‌های باکس دانلود** (کیفیت‌ها و قسمت‌ها) با انیمیشن کند و روان (~۰٫۹ ثانیه، منحنی ease) باز و بسته می‌شوند؛ قبلاً اکاردیون قسمت‌ها بدون انیمیشن و ناگهانی باز می‌شد.
- **دسته‌بندی‌ها** به حدود ۱۲ گروه ادغام شدند (مثلاً «اکشن و ماجراجویی»، «ترسناک و هیجان‌انگیز»، «انیمیشن و انیمه»…). با باز کردن هر گروه، محتوای همهٔ ژانرهای عضو آن نمایش داده می‌شود.
- **جستجو**: نتایج هر سایت به محض رسیدن نمایش داده می‌شود و بقیه در پس‌زمینه ادامه می‌یابد (دیگر منتظر کندترین سایت نمی‌ماند). تأخیر تایپ از ۵۰۰ به ۲۸۰ms، تایم‌اوت از ۱۰ به ۶ ثانیه و تعداد نتیجهٔ هر درخواست کمتر شد؛ جستجوی قبلی با تایپ جدید لغو می‌شود و نتایج ۵ دقیقه کش می‌شوند.
- **چیپ‌های دسته‌بندی صفحهٔ خانه**: با هر رفرش، ۶ دستهٔ تصادفی پیشنهاد می‌شود.
